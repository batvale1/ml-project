# Данные Review Decoder

Источник: [Women's E-Commerce Clothing Reviews, Kaggle](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews).

Скачайте архив со страницы источника, распакуйте и поместите исходный файл по пути:

```text
external/Womens Clothing E-Commerce Reviews.csv
```

Вся папка `external/` исключена из Git. Данные не включаются в репозиторий и не скачиваются автоматически при запуске анализа.

Проверенная версия: 23 486 строк, 11 колонок с техническим индексом экспорта. SHA-256:

```text
bd93cc515747ad1f87b8bc863c9e40da758509e6db6506a96d06976e61e36ee0
```

Проверить файл в PowerShell:

```powershell
Get-FileHash -LiteralPath 'external/Womens Clothing E-Commerce Reviews.csv' -Algorithm SHA256
```

Если контрольная сумма отличается, ноутбук останавливается: сначала нужно проверить версию файла и пересчитать связанные с ней выводы.

| Поле | Содержание | Роль в проекте |
|---|---|---|
| Первый столбец без имени | Индекс экспорта | В аудите переименовывается в `source_row_id`; не вход модели |
| `Clothing ID` | Идентификатор товара | Концентрация отзывов и групповой анализ; запрещён основной модели |
| `Age` | Возраст покупательницы | Описательный EDA |
| `Title` | Заголовок отзыва | Дополнительный текстовый эксперимент |
| `Review Text` | Основной английский текст | Основной вход классификатора |
| `Rating` | Оценка от 1 до 5 | EDA; запрещена основной модели |
| `Recommended IND` | Рекомендация: 1 — да, 0 — нет | Целевая переменная |
| `Positive Feedback Count` | Число положительных откликов на отзыв | EDA; запрещено основной модели |
| `Division Name` | Товарная линия | Возможный дополнительный категориальный признак |
| `Department Name` | Отдел одежды | Возможный дополнительный категориальный признак |
| `Class Name` | Класс одежды | Возможный дополнительный категориальный признак |

Исходный CSV сохраняется без изменений. В ноутбуке отдельно доступны исходная таблица, таблица аудита и подготовленная текстовая выборка. Правила обработки и количество исключённых строк фиксируются в `reports/tables/cleaning_ledger.csv`.

Локальный `data/processed/review_manifest.csv` содержит исходные идентификаторы строк, метки и хеши нормализованных текстовых групп. Он нужен для последующего разбиения без пересечения одинаковых текстов; сам по себе train/test-разбиением не является. Каталог `data/processed/` исключён из Git.

В Git сохраняются выполненный ноутбук, выбранные рисунки и небольшие агрегированные таблицы. EDA исследует полный датасет; будущую тестовую часть из него нельзя называть полностью неизученной. Сведения об условиях сбора, временных метках и авторах ограничены, поэтому причинные выводы и перенос на другие магазины требуют отдельной проверки.
